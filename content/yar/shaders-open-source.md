2026 年 10 月 6 日，官方账号 shaders（@npm_i_shaders）发了一条很短的帖：Shaders is now open source。

人话讲，这是一套能嵌进网页的视觉特效组件，不用自己写着色器。渐变、噪点、玻璃、金属、光、扭曲、转场、模糊、光标效果，都可以当组件用，还能嵌套、混合、遮罩。React、Vue、Svelte、Solid、JavaScript 共用同一套 props，安装是 npm install shaders。

开源的是引擎和这 200 多个 WebGPU 组件，不是整个网站，也不是预设库。设计器还在 [shaders.com](https://shaders.com)，可以把组件树导出成对应框架的代码。README 写设计和导出免费。官方说被数千个网站、16000+ design engineers 使用。

还有一句边界：这是在网页里跑的 GPU 效果，不是贴进公众号正文就能动的图。浏览器不支持 WebGPU 时，官方文档说画面会保持透明，onReady 也不会触发。

## 普通人能拿来用的，大概是这四块

### 1. 给自己的网站、落地页、作品集加一层动态效果

你有站点、产品页、个人作品集，想让背景或某个区块动起来，又不想学图形学，这就是组件库的用法。

能免费用的是开源组件本身。成套预设、网站板块、无水印的高清视频和图片渲染，仍在 Pro 里。设计器可以帮你搭组件树再导出代码，那不等于整站模板白送。

### 2. 接网页类的活时，商用路径更干净了

许可证页（2026 年 10 月 6 日更新并生效）写得很直白：引擎、每个 shader 组件、Vue / React / Svelte / Solid / JavaScript 绑定、CLI，以及 shaders 这个 npm 包和该 GitHub 仓库里发布的软件，是 MIT。可以商用、修改、分发。

接客户网站、模板、产品时，用这些开源组件，不必先买授权。

设计器、预设、合集、sections，以及由它们生成的内容，不在 MIT 里，另有平台协议。自己写的代码、在平台从零设计并导出的东西，归用户。

### 3. 做模板、小产品、组件库时，把效果嵌进去

与其从零做视觉特效，不如把这套积木嵌进你已经在卖的东西：站点模板、落地页组件、小产品界面。

官方帖也点过：可用于客户网站、模板、产品、库，可为任意框架导出代码，免费。

嵌的是开源组件和你自己搭的效果。不要把“开源了”理解成可以把 Pro 预设库拆出来再卖一遍。

### 4. 做小工具时，调用现成视觉，而不是自己做一套

README 写了几条给编程助手用的方式：npx shaders skill，或 npx skills add shader-effects-inc/shaders，给编程助手装 skill；npx shaders@latest install-mcp 配 MCP，并写免费账号也能用；另外还有 llms.txt。

如果你在做 PPT、视频封面或生成类小工具，可以调用现成组件，不必自己搓一套很糙的效果。

Pro 预设、通过 CLI 和 MCP 使用 Pro 预设、无水印高清导出，不在免费范围。免费账号能摸到的是开源组件和基础用法，不是整套成品质感。

## 我的看法

开源切得很清楚：引擎和 200 多个组件走 MIT。预设、板块、去水印渲染、Framer 一键安装、编辑器无限版本历史、Discord 和优先支持，仍是 Pro。
